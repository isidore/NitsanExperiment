# Shared Calendar

A calendar that multiple people can access and add events to, to coordinate scheduling within a group.
Self-contained (does not sync to personal calendars). Built in a Learning Hour.

Stack: TypeScript · Vue 3 · Vite · Vitest

```sh
npm install
npm test        # run all tests once
npm run dev     # http://localhost:5173
```

`mockup/shared-calendar.html` is the static HTML mockup of the first happy-path story.
